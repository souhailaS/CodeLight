## Share it, or keep it

Everything for a folder lives in one file under `.vscode`, either `codelight.json` or `codelight.json.gz`. A workspace with several folders gets one file each.

Commit it and everyone who pulls the repository reads the same notes. Run **CodeLight: Keep the Notes Out of Git** instead and the file goes into `.gitignore`, so nothing you jot down while reading becomes someone else's diff. **Take the Notes Out of .gitignore** removes that entry again, and the notes travel once you commit the file.
